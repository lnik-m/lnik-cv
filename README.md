## 📖 About

**lnik-cv** is my personal portfolio and resume website — a fast, animated, and minimalistic space to showcase who I am, what I do, and what I've built

Built with **Next.js 16** and deployed on **Netlify**, it combines modern frontend technologies with a focus on performance, accessibility, and clean design

---

## ✨ Features

- ⚡ **Blazing fast** — built with Next.js 16 and Tailwind CSS 4
- 🎨 **Smooth animations** — powered by Motion (Framer Motion)
- 📱 **Fully responsive** — works on all screen sizes
- 🧩 **Interactive elements** — subtle hover effects and transitions
- 📄 **Clean typography** — focused on readability and clarity
- ♿ **Accessible** — semantic HTML and keyboard-friendly
